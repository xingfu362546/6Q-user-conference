# 用户标签后台 · 逻辑对齐摘要（Grill 结论）

本文档汇总产品与研发评审后的业务规则，与 `user-tag-admin/` 原型一致。

## 全局

| 项 | 结论 |
|----|------|
| 菜单框架 | 全站统一侧栏（标签中心 3 项 + 数据资产 2 项），由 `js/ut-shell.js` 注入 |
| 标签层级 | 仅两级；一级固定预置，运营只建二级；暂不需要三级 |
| 一级「新增」 | 在标签管理树表一级行操作，在该分类下新建二级（非新建一级） |

## 1. 标签管理

| 项 | 结论 |
|----|------|
| 覆盖人数 | 展示**上次成功版本**命中人数；计算失败时仍显示该值 |
| 一级行 | 不展示覆盖人数、计算状态、编码等 |
| 二级操作 | 编辑、**复制规则**、执行历史、立即计算、停用 |
| 顶栏按钮 | 「新增二级标签」保留 |

## 2. 新增标签

| 项 | 结论 |
|----|------|
| 数据源 | 必填；创建后**运营不可改**，仅开发可变更 |
| 规则类型 | **用户属性**（数据表→字段）、**行为事件**、**页面行为**（行为类必填时间范围） |
| 属性字段来源 | 数据表元数据技术字段名，不预置中文业务字段 |
| 规则解读 | 顶部自然语言摘要 + 预估人数试算（见 `docs/RULE_OPTIMIZATION.md`） |
| 规则逻辑 | 顶层与嵌套均支持 **且 / 或** 切换 |
| 保存并计算 | **立即触发计算**（含手动更新模式） |
| 复制规则 | 新建页预填规则与数据源；名称需重填 |
| 更新方式 | 手动 / 例行；日常手动模式仍可在列表点「立即计算」 |

## 3. 执行历史

| 项 | 结论 |
|----|------|
| 入口 | **仅二级标签** |
| 版本号 | **计算执行日期** YYYYMMDD |
| 表格标签列 | 固定为当前二级标签名 |
| 失败版本 | 侧栏展示；右侧**空表 + 错误信息**；不可导出 |

## 4. 数据接入

| 项 | 结论 |
|----|------|
| 地址 | 只读输入框 + 复制；**仅开发可改** |
| 不展示 | project、token、JSON 样例 |
| 不做一期 | 端点健康、最近上报量 |

## 5. 数据表管理

| 项 | 结论 |
|----|------|
| 权限 | **全员只读**，不可删表 |
| 字段详情 | **右侧抽屉** |
| 不做 | 「被 N 个标签引用」列 |
