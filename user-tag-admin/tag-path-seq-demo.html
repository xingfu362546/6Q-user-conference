匹配流程（子序列模式）

flowchart TD B[定时批次 route_logs] --> S[按 enter_time 排序] S --> W[截取时间窗口] W --> M{子序列匹配 A→B→C?} M -->|是| H[命中标签] M -->|否| N[未命中]

上报 payload 示例（推荐）

{
  "member_id": "m10001",
  "batch_time": "2025-04-06T10:00:00Z",
  "routes": [
    { "path": "/pages/course/list", "enter_time": "…09:12:01" },
    { "path": "/pages/course/detail", "enter_time": "…09:12:45" },
    { "path": "/pages/user/profile", "enter_time": "…09:13:02" },
    { "path": "/pages/order/confirm", "enter_time": "…09:14:10" }
  ]
}

上例在子序列模式下命中 A=list → B=detail → C=confirm（中间可插 profile）。
