# 计划详情（打卡计划）admin（v3.1.0）

## 页面定位

创建打卡计划后的**只读详情页**。计划基础信息在「新增打卡计划」维护；话题绑定与任务在「话题编辑 → 打卡配置」维护。本页聚合展示计划信息、引用该计划的话题，以及各话题下的**打卡明细**。

## 页面结构

- 标题：计划详情
- Tab：**基础信息 | 关联话题 | 打卡统计**（已取消「任务概述」）
- 白底管理端样式

## Tab 说明

### 1. 基础信息

与「新增打卡计划」表单字段只读对照：计划编号、计划名称、周期计划、备注、创建时间、创建人、计划状态。

### 2. 关联话题

展示在「话题编辑 → 打卡配置」中选择了本计划的话题。

| 列 | 说明 |
|----|------|
| 话题编号 / 名称 | — |
| 关联时间 | 绑定计划时间 |
| 话题状态 | 已发布等 |
| 操作 | 查看话题（跳转） |

**交互约束：** 本页**不支持解除关联**；修改或移除计划绑定须前往对应话题的编辑页 → 打卡配置。

### 3. 打卡统计

聚合所有关联话题下的**用户提交明细**列表，列与话题「打卡配置」任务表对齐。

**任务类型（仅两种）：** `打卡类型` | `授课类型`

| 列 | 说明 |
|----|------|
| 所属话题 / 任务标题 | 来源 |
| 任务类型 | 打卡类型 或 授课类型 |
| 任务详情 / 任务时间范围 | 来自任务配置 |
| 打卡类型 | 仅「打卡类型」任务有值；授课类型为 — |
| 授课产品 | 仅「授课类型」任务有值；打卡类型为 — |
| 目标打卡天数/次数 / 执行群体 | 来自任务配置 |
| 用户 / 用户ID / 提交时间 | 提交人信息 |
| 语音 | 打卡类型且任务要求语音时：已上传/未上传；否则 — |
| 打卡内容可见 / 附件 | 打卡类型相关；授课类型可见为 — |

不含：明细编号、审核状态、操作列。

支持筛选：所属话题、任务类型。工具栏右侧提供 **导出** 按钮，按当前筛选结果导出 CSV。

## 数据关系

```
新增打卡计划 → 计划实体
话题编辑·打卡配置 → 选择计划 + 配置任务；用户打卡产生明细
计划详情 → 只读：计划信息 + 引用话题列表 + 跨话题打卡明细聚合
```

## 已确认产品决策

1. 不单独提供「任务概述」Tab（多话题场景下任务分散在各话题，避免重复维护视图）。
2. 「打卡统计」= 关联话题打卡明细列表。
3. 关联话题不可在本页解除，仅能在话题编辑中修改。
