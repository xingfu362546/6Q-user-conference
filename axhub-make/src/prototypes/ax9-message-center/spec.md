# 消息中心（v3.0.0） new — 按原型 1:1 还原

## 页面结构（依截图）

1. **状态栏**：左上 HD / 5MB/s，右上 100% 12:00。
2. **顶栏**：左侧浅灰方框占位（返回/头像）、居中标题「系统通知」、右侧方框内三角图标。
3. **左侧竖栏**（约 80px）：三项纵向排列，每项为「浅灰方框图标 + 文案 + 橙点（未读）」：
   - 消息（有橙点）
   - 评论（有橙点）
   - 点赞（无橙点）
4. **右侧主区**：可滚动通知列表。每条卡片：
   - 浅灰底、圆角、轻阴影；
   - 标题加粗黑字，如「【6Q社区活动】打卡活动正式开始」；
   - 描述两行灰字：「小Q邀请您参加调研,参与获取大礼!有机会获取大奖...」；
   - 底部：左侧「6Q社区小助手」，右侧时间（未读条目前有红色小圆点 + 「21小时前」，已读为「02-07」「2025-02-07」等）。
5. **FAB**：右下角橙色圆形按钮，白色「+」号。
6. **底部导航**：首页 | 消息 | 我的，每项上方为占位图标框（X），当前为「消息」页。

## 组件清单

- 状态栏、顶栏（占位 + 标题 + 三角）
- 左侧分类导航（图标 + 文案 + 未读橙点）
- 通知卡片（标题、描述、发送方、时间/未读红点）
- FAB（橙底白 +）
- 底部 Tab（首页/消息/我的）

## 样式要点

- 移动端宽度约 375px，白底。
- 卡片背景 #f5f5f5，阴影 0 1px 2px rgba(0,0,0,0.06)。
- 未读：左侧分类为橙色圆点 #F59A23，卡片时间为红色小圆点 + 时间文案。
- FAB 背景 #F59A23。
