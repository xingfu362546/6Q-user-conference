# Ax9 Community 设计规范

基于 Axure 原型 [axhub.im/ax9/5f9ba66c12c9c6b4](https://axhub.im/ax9/5f9ba66c12c9c6b4) 提取的社区 APP 主题规范。

## 1. 视觉关键词与品牌气质

- **产品类型**：社区 / 话题 / 打卡类 APP 用户端
- **气质**：清晰、中性、偏工具感；主色蓝传递信任与效率
- **适配**：兼顾移动端与桌面预览

## 2. 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 Primary | `#169BD5` | 按钮、链接、强调操作 |
| 背景 Background | `#F0F2F5` | 页面底衬 |
| 前景/正文 Foreground | `#333333` | 主要文字 |
| 卡片/表面 Card | `#FFFFFF` | 卡片、输入区背景 |
| 弱化 Muted | `#F2F2F2` / `#7F7F7F` | 次要背景、辅助文案 |
| 强调 Accent | `#F59A23` | 提示、标签、警示类 |
| 辅助 Accent Secondary | `#5F51FB` | 次要强调、标签 |
| 边框 Border | `#E0E0E0` | 分割线、输入框边框 |

## 3. 排版系统

- **字体族**：苹方（PingFang SC）、微软雅黑（Microsoft YaHei）为优先，sans-serif 兜底
- **字号层级**：
  - 10px：辅助说明、角标
  - 12px：次要信息、表单项说明
  - 13px：正文默认
  - 14px：小标题、列表标题
  - 16px：区块标题
  - 18px：页面主标题
- **字重**：400 常规、700 粗体

## 4. 组件风格

- **圆角**：2px（小组件）、5px（输入/按钮）、10px（卡片）、20px/40px（大卡片/头像）
- **阴影**：轻阴影 `0 0 8px rgba(0,0,0,0.098)`；卡片 `5px 5px 5px 0 rgba(0,0,0,0.2)`
- **间距**：2 / 8 / 10 / 20 / 35px 为常用间距尺度

## 5. 状态与交互

- 主按钮：主色填充，白字
- 次要操作：边框或浅底
- 悬停/焦点：边框或背景略加深，ring 使用主色

## 6. 适配策略

- 以移动端为主视觉参考，桌面端保持相同 token，通过布局与断点适配
