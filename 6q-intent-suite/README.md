# 6Q 意向分析 · 原型套件

本目录打包四端子项目；**本目录根仅有一个 `index.html`**，即功能清单总页。

## 入口

打开 [`index.html`](./index.html)（或仓库根跳转页）。

## 子项目

| 目录 | 说明 | 原型入口 |
|------|------|----------|
| `6q-interviewer-portal/` | 面谈官门户 | `login.html` |
| `6q-conference-app-prototype/` | 会务 APP | `index.html` |
| `6q-conference-prototype/` | 会务后台 PC | `index.html` |
| `user-tag-admin/` | 标签系统 | `tag-list.html` |

跨端资源引用使用相对路径（子项目互为兄弟目录）。
