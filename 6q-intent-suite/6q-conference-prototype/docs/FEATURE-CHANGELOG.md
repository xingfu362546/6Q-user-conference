## v1.0.4 · 2026-08-27（当前封版）

**主题：** 学员画像分析助手大型工作台

| 功能 | 说明 |
|------|------|
| 大型双栏助手 | 原右下角小弹窗升级为约 90vw × 88vh 工作台；关闭后回到原画像位置 |
| 三大意图 | 兴趣解读 / 下一步跟进 / 课程产品智能匹配 |
| 综合数据依据 | 用户标签、行为埋点、历史跟进、报读购买及学习记录 |
| 产品智能匹配 | 工作人员确认条件后执行；A+B 数据汇聚与可解释阶段动效 |
| 推荐详情 | 主推+备选、课程产品介绍、3个当前/未来课务期数、全部商品及预算标识 |
| 个人历史 | 会话按工作人员隔离；支持搜索、推荐版本和历史数据快照 |
| 进阶与权益 | 标签与报读记录取最高层级；已购买=有资格，已报读=资格已核销，可建议复训 |
| 失败兜底 | 保留会话和条件，展示预算内 Mock 兜底产品并明确标识 |
| 两端复用 | 会务后台与已授权面谈官门户共用；会务 APP 不承载大型工作台 |
| 礼包权益（增补） | 匹配时读取事业说明会「意向了解方向」；含导师/天使才展示礼包区，与课程产品分区；无意向不渲染该区域 |
| 意向分析洞察快照（增补） | 抽屉 AI 固定「结论 / 依据 / 下一步」；列表推荐列=课程一行 + 有方向才礼包一行；闸门同源、可约谈时间不单独出礼包。**不改画像分析助手** |

**入口：** [会务后台画像](../conference-student-profile.html?id=m10009) · [面谈官门户画像](../../6q-interviewer-portal/student-profile.html?id=m10009)

**设计：** [`docs/superpowers/specs/2026-08-27-student-analysis-assistant-design.md`](../../../docs/superpowers/specs/2026-08-27-student-analysis-assistant-design.md) · [《导学师场景结构》](../../../docs/course-student-intent/导学师场景结构.md)

## v1.0.3 · 2026-08-05

**主题：** 6Q 面谈官独立 PC 门户（只读查档）

> **开发交接（v1.0.0–v1.0.3 全量）：** [docs/course-student-intent/HANDOFF-DEV-v1.0.0-v1.0.3.md](../../docs/course-student-intent/HANDOFF-DEV-v1.0.0-v1.0.3.md)

### 模块：面谈官门户（新）

| 功能 | 说明 |
|------|------|
| 独立门户 | 目录 `6q-interviewer-portal/`；账号来自会员；不能进运营后台 |
| 登录 | 手机号+密码 / 邮箱+密码 + 图形验证码 |
| 会务选择 | 仅进行中且本人为面谈官；原型 mock 2～3 场；空态「当前无正在进行中的会务」 |
| 学员意向列表 | 呈现对齐运营后台意向分析；点姓名进画像；无策略配置/导出 |

| 画像档案 | 复用后台口径（含行为/跟进查看更多 + AI 问答） |
| AI 对话预设 | 4 chips：分析跟进 / 沟通话术 / 消费能力 / 课程购买建议（按消费力分档：免费直播·社区·免费课 vs 高客单）；自由输入接兴趣点·行为汇总·标签解读 |

**入口：** [面谈官门户](../../6q-interviewer-portal/login.html)

## v1.0.2 · 2026-08-05

**主题：** 画像档案增强 + 行为/跟进明细归档案；意向分析列表精简

### 模块：学员信息 / 画像档案

| 功能 | 说明 |
|------|------|
| 家庭组 | 中栏·基础信息下；家庭ID + 序号/编号/姓名/性别/身份/手机；高亮本人 |
| 关系图谱 | 右栏替换「跟进类型占比」；推荐/归属双边·1跳·当前生效；环形分区交互图（ECharts） |
| 基础信息补齐 | 对齐会员详情：身份状态、关系人摘要、认证人口属性、社会属性 |
| 社区话题活跃 | 按话题名称细拆（非仅分类） |
| 图表口径 | 购课条形 + 近30天行为折线；不做正式商机诊断条 |
| AI 分析对话 | 右下角小弹窗；针对当前学员自然语言追问，基于档案事实 mock 回复 |
| 近期行为四 Tab | 社区/学习/视频/直播；卡片各预览 5 条（字段口径：话题内容时间 / 课程次数更新 / 视频观看 / 直播团队场次时长成交） |
| 行为查看更多 | 右侧抽屉，四 Tab 切换看全量 |
| 跟进查看更多 | 右栏跟进卡片预览 + 抽屉全量（会员详情字段；承接原意向「历史跟进」） |

**入口：** [学员信息](../conference-students.html) → [画像档案](../conference-student-profile.html?id=m10009)

### 模块：学员意向分析

| 功能 | 说明 |
|------|------|
| 列表列更名 | 「跟进内容」→「跟进内容（当前会务）」 |
| 行为明细迁出 | 删除社区/学习/视频/直播列与抽屉 Tab；行为深挖统一在画像档案 |
| 历史跟进迁出 | 抽屉不再含历史跟进；改由画像「跟进记录 · 查看更多」承接 |
| 明细抽屉精简 | 仅保留标签命中 + 洞察与推荐 |
| 姓名跳转档案 | 点击学员姓名打开画像档案（页顶落地） |

**入口：** [学员意向分析](../conference-student-intent.html)
