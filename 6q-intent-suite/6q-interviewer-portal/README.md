# 面谈官门户（v1.2.4）

本次版本：门户原生五业务页、统一画像入口与完整示例、会务订单与问卷页签、跟进交互、筛选折叠和单一导出入口；已提交问卷详情展示8道示例问题及回答。

独立 PC 门户原型：会员登录 → 选择进行中会务 → 学员意向列表 → 画像档案（含分析助手）。

## 入口

- 登录：`login.html`
- 会务选择：`conference-select.html`
- 意向列表：`student-intent.html`
- 学员列表：`students.html`；点击学员6Q姓名进入对应ID画像档案。
- 普通画像档案：`student-profile.html?id=m10009`，不显示本场会务页签。
- 会务画像档案：`student-profile.html?id=XE78PV&from=conference&conferenceId=cf_a`，新增本场会务订单、本场会务学员问卷，以及面谈跟进和答疑跟进按钮。

## 画像档案本轮调整

- 会务入口显式携带会务ID，普通入口不读取上次选择会务作为展示条件。无效学员ID或姓名/手机号与ID不一致时明确提示，不回退到其他学员。
- 订单保留序号、订单ID、交易类型、交易明细、购买数量、应收金额、实收金额、订单状态、创建时间、完款时间；筛选含创建/完款时间范围、下单人、下单人手机、订单ID及交易类型。
- 问卷保留序号、问卷名称、状态、更新时间、操作，支持名称/状态筛选及查看详情；未提交无更新时间和答案。源未提供题目答案，详情使用明确空态。
- 跟进按钮复用会务跟进表单，按学员ID与会务ID保存本地演示记录，档案和该会务跟进列表可查看；附件仅演示文件名，不上传。
- 同页全部页签共用一份说明，切换保持说明阅读位置、既有画像行为页签和表单输入；普通画像既有模块及流程保留。
- `students.html` 与 `student-intent.html` 的姓名入口统一打开 `student-profile.html`；头部学员信息保持入口身份。当前原型详细画像无需逐人绑定，统一复用原有完整示例，展示基础资料、家庭、购买/资格、评价、历史跟进、客服、退款、四类行为、图表及AI入口；以简短“原型演示数据”提示说明数据性质。未知ID仍为空态。
- “档案画像 / 本场会务订单 / 本场会务学员问卷”页签位于学员信息卡下方、本场会务跟进上方；切换页签仍显示学员信息卡。所有有效会务入口均展示完整订单、问卷示例，不限定 `cf_a + XE78PV`；新录入跟进仍按学员ID与会务ID保存。正式业务说明见版本根目录《需求说明》。
- 学员列表仅一个“导出”按钮，统一保留原现场导出的全部29个业务字段，按当前筛选输出带日期CSV。
- 五业务页面及画像订单/问卷筛选按实际布局判断多行，默认显示第一行，多行时可展开/收起；查询和重置始终可见。切换、缩放保留条件，单行无多余按钮；意向页只有一个搜索条件，无需增加。
