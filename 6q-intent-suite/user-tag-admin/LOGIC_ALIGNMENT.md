# 用户标签后台 · 逻辑对齐摘要（Grill 结论）

> **原型版本：v1.1**（相对 v1.0：圈选方式由可视化规则改为 NL→SQL）  
> 交接详见：`docs/course-student-intent/HANDOFF-v1.1.md`

本文档汇总产品与研发评审后的业务规则，与 `user-tag-admin/` 原型一致。

## 全局

| 项 | 结论 |
|----|------|
| 菜单框架 | 全站统一侧栏（标签中心 3 项 + 数据资产 2 项），由 `js/ut-shell.js` 注入 |
| 标签层级 | 仅两级；一级固定预置，运营只建二级；暂不需要三级 |
| 一级「新增」 | 在标签管理树表一级行操作，在该分类下新建二级（非新建一级） |
| 原型版本 | **v1.1** |

## 1. 标签管理

| 项 | 结论 |
|----|------|
| 覆盖人数 | 展示**上次成功版本**命中人数；计算失败时仍显示该值；本版本「无效」后以有效人数为准 |
| 一级行 | 不展示覆盖人数、计算状态、编码等 |
| 二级操作 | 编辑、**复制**（带 NL + 已确认 SQL）、执行历史、立即计算、停用 |
| 顶栏按钮 | 「新增二级标签」保留 |

## 2. 新增/编辑标签（v1.1）

| 项 | 结论 |
|----|------|
| 圈选方式 | **自然语言 → 智能体生成 SQL**（一期主路径） |
| ~~可视化规则配置~~ | **一期不做**：原条件行/条件组/且或构建器已在页面中注释保留；脚本仍在仓库（`ut-rule-builder.js` 等）但不加载 |
| 数据范围 | **固定数仓连接 + 研发表白名单**；页上只读展示，运营不可切换 |
| SQL 契约 | 只读查询；结果集有且仅有一列 **`member_id`**；禁止 DDL/DML |
| 主流程 | **保存草稿** → **生成 SQL**（解读 + 预估）→ **确认并计算** |
| 例行/立即计算 | **复用已确认 SQL**，不每次调 AI；改自然语言须重新生成后再确认 |
| 改 NL 脏状态 | 旧 SQL 保留 + 告警；禁用「确认并计算」，须重新生成 |
| 更新方式 | **手动 / 例行每日**（每标签独立时刻，Asia/Shanghai）；不做参考图中的「实时查询」 |
| 保存草稿 | 存名称、NL、更新方式；未确认 SQL 不用于例行 |
| 复制 | 新建页预填 NL 与已确认 SQL；名称需重填 |

## 3. 执行历史（v1.1）

| 项 | 结论 |
|----|------|
| 入口 | **仅二级标签** |
| 版本号 | **计算执行日期** YYYYMMDD |
| 成功版本 Tab | **命中用户**｜**本次 SQL** |
| 本版本无效 | 单行操作；**仅剔除当前版本**命中；重算仍可能再命中（一期不做持久黑名单） |
| 失败版本 | 侧栏展示；右侧**空表 + 错误信息**；不可导出 |

## 4. 数据接入

| 项 | 结论 |
|----|------|
| 地址 | 只读输入框 + 复制；**仅开发可改** |
| 不展示 | project、token、JSON 样例 |
| 不做一期 | 端点健康、最近上报量 |

## 5. 数据表管理

| 项 | 结论 |
|----|------|
| 权限 | **全员只读**，不可删表 |
| 字段详情 | **右侧抽屉** |
| 用途（v1.1） | 展示研发白名单内可用表，供运营理解「数据范围」 |
| 不做 | 「被 N 个标签引用」列 |
