# 标签规则 · 通用选项与组件说明

> 选项定义见 `js/ut-rule-options.js`；渲染见 `js/ut-rule-builder.js`

## 统一行结构

每条条件：

```
[条件类型 ▼]  [配置区：三面板之一]  [删除]
```

- 切换类型只切换 `[data-panel]` 显隐，三个面板 DOM 始终存在且已渲染完整。
- **不会出现空白**：不再使用空的 `data-rule-fields="default"` 占位。

## 通用组件

| 组件 | 用于 | 字段 |
|------|------|------|
| **时间范围** `ut-cmp-time` | 行为事件、页面行为 | 最近 N 天 / 固定区间 |
| **比较** `ut-cmp-compare` | 属性、事件聚合、页面指标 | 比较符 + 值（随 valueType 变） |

### 通用比较符（按 valueType）

- `string`：等于、不等于、包含、不包含、为空、不为空
- `number`：等于、不等于、大于、大于等于、小于、小于等于、介于
- `date`：早于、晚于、介于、等于
- `bool`：为真、为假
- `match`（页面匹配）：等于、包含、前缀匹配、正则匹配

## 三类条件专有字段

### 用户属性（从数据表选字段，通用）

1. **数据表**：来自数据表管理 / 接口（原型 `UT_TABLE_CATALOG`，`role=profile`）
2. **字段**：展示 `字段名 (物理类型)`，值为技术列名，**不写死中文业务名**
3. **比较符 + 值**：由列 `dataType` 映射为 `string|number|date|bool` 后走通用比较组件

上线：与「数据表管理 → 查看字段」同一套元数据 API。

### 行为事件

- 时间范围 → 做过/未做过 → 事件 → （做过时）聚合 + 比较

### 页面行为

- 页面维度 → 匹配方式 → 值 → 指标 → 比较 + 单位 → 时间范围

## 扩展方式

上线时将 `UT_RULE_OPTIONS` 中数组改为接口返回即可，**不必改面板结构**。
