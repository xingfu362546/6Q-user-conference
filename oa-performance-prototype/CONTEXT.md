# Context · OA 内部绩效（原型子项目）

## 产品范围（待 Grill 确认）

- **域**：企业 OA 中的 **内部绩效管理**（月度考核、目标对标、过程督查、结果评价、绩效反馈等）。
- **本工作区职责**：业务对齐、页面矩阵、HTML 可交互原型；**非**生产后端实现。
- **双端**：小程序 + OA 应用（职责划分见 `DESIGN_SESSION.md`）。

## 已知业务线索（来自现有 Excel V1.2，待你确认/修正）

| 术语 | 初步理解 |
|------|----------|
| 月度绩效管理程序 | ①月初对标 → ②月中过程督查 → ③月底结果评价 → ④绩效反馈（必要时改进计划）→ ⑤加减分 |
| 综合分数 | 自评 × 20% + 上级领导评分 × 80% |
| 指标结构 | 核心绩效指标（V%）+ 常规绩效指标（X%），V%+X%=85%；另有加减分等 |
| 岗位模板 | 至少区分：总监/经理 与 主管/职员 两套表结构 |
| KR 字段 | 指标类型、关键目标(O)、考核目标(SMART)、KR 权重、考核标准、关键成果(M)、自评/上级/综合分 |
| 目标数据来源 | **终态**：项目系统拉取员工目标；**MVP 原型**：员工手动填 KR，预留导入占位 |
| 考核类型 | **月度绩效表 V1.2** + **季度绩效表 V1.2**（见 `templates/`） |
| 考核计划/批次 | HR 手工或系统自动生成计划，按开放时间 **发放** 填写任务（见 `docs/BATCH_PLAN_CONCEPT.md`） |
| 提前对标 | 填**本月/本季** KR；**当月/当季开放期内**填写，不强制月初 |
| 评分权限 | 仅本人、直接上级、总经理可填分；其他人无待办 |
| 员工可见性 | ❌ 员工 **不可见上级对自己的评分**（保密）；过往提交仅回看 **自有填写** + 状态 |
| 员工列表 | 当前待办 / 逾期 / 过往提交（无查分 Tab） |

> ⚠️ 部分术语来自清单与 Excel 解析，**以 Grill 会话为准**。
