## 阶段枚举

| key | 展示名 |
|-----|--------|
| `not_started` | 待填写 |
| `filling` | 填写中 |
| `pending_supervisor` | 待上级评 |
| `pending_division` | 待分管评（**仅季度·非同人**） |
| `pending_confirm` | 待确认 |
| `confirmed` | 已确认 |

兼容：旧 `completed` 映射为 `confirmed`。

逾期（D1）：仍为待填写/填写中 + **逾期**角标；HR 解锁后续填。

草稿：挂在**待办任务 id**，无独立草稿箱。

---

## 月度（员工步骤条 5 步）

```
待填写 → 填写中 → 待上级评 → 待确认 → 已确认
```

| 规则 | 说明 |
|------|------|
| 进待确认 | **上级提交即可**，不等分管核定 |
| 分管 | 确认前可随时 **改核定总分**；**无**确认按钮 |
| 待确认展示 | 默认系统汇总分；有核定 → **核定分 +「已调整」** |
| 改总分 | 不动分项；**仅清零已 ✓ 的确认态**（Q9-A） |
| 已确认 | **员工 + 上级** 均 ✓ → **禁止**再改总分 |

---

## 季度（员工步骤条 6 步；同人合并 5 步）

```
待填写 → 填写中 → 待上级评 → 待分管评* → 待确认 → 已确认
         *mergedReview 跳过待分管评
```

| 规则 | 说明 |
|------|------|
| 进待确认 | 非同人：分管逐项评提交后；同人：上级一次提交后 |
| 分管 | 逐项评 + 改总分；**待确认有确认按钮** |
| 已确认 | **员工 + 上级 + 分管** 均 ✓ → **禁止**改总分 |
| 改总分 | 同月度（仅清零已 ✓ 者） |

---

## 待填写 vs 填写中

| 态 | 条件 |
|----|------|
| 待填写 | 计划已发放，员工从未「开始填写」且无该待办草稿 |
| 填写中 | 已开始或该待办上已有保存进度 |

---

## 改核定总分交互

- 必确认方 **全部 ✓** 前可改（含待确认进行中）
- 全部 ✓ 后：按钮 **disabled**，提示「全部人已确认，无法修改总分」
- 改分后：`divisionAdjusted=true`，已确认的人需重新确认
