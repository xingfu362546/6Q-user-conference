# HR 计划 · 参与范围 & 模板匹配 · Grill 记录

> **日期**：2026-06-03  
> **状态**：已确认，原型已按本文实现  
> **关联**：`hr-plan-create.html` 步骤 2/4/5、`hr-plan-detail.html` 范围包管理

---

## 1. 核心模型

```
一条考核计划（同周期全公司唯一）
  └─ 多个「范围包」（Scope Pack）
       ├─ 组织树 / 筛选 / 搜索 → 勾选人员
       ├─ 互斥：一人仅属一个范围包
       ├─ 一包 → 一张模板（HR 手动绑定）
       └─ 状态：未发放 | 已发放（已发放锁定人选+模板）
```

**与旧原型差异**：废弃「全公司 checkbox + 部门/职级多选 + 人群×职级自动矩阵」；改为 **范围包 + 组织树 + 手动模板**。

---

## 2. 决策表（Q1–Q13）

| # | 议题 | 决策 |
|---|------|------|
| Q1 | 一人几个范围包 | **仅一个**；已在其他包的人不可再选 |
| Q2 | 未分配的人 | **不参与**；可在同计划内后续新建范围包补发 |
| Q3 | 后续补人 | **只能新建范围包**；已分配人员在树中 **禁用** |
| Q4 | 勾部门 | **级联全选 + 展开微调**；已占用人跳过/禁用 |
| Q5 | 模板匹配 | **一包一模板**，HR 在步骤 4 手动选择 |
| Q6 | 发放时机 | **每个范围包可单独发放** |
| Q7 | 已发放后 | **锁定**（人选+模板不可改）；补人仅新建包；单人走催办/解锁/退回 |
| Q8 | 组织树 | **全集团树 + 顶栏搜索** |
| Q9 | 范围包命名 | **默认「范围N」，可改名** |
| Q10 | 人群×职级自动规则 | **不参与模板匹配**；职级/岗位仅作 **选人筛选** |
| Q11 | 筛选交互 | **树过滤（A）+ 右侧符合条件人员列表（C）** |
| Q12 | 筛选项 | **职级枚举多选 + 岗位关键字搜索** |
| Q13 | 步骤 5 | **汇总 + 勾选要发的范围包 → 发放选中** |

---

## 3. 向导步骤

| 步 | 名称 | 内容 |
|----|------|------|
| 1 | 类型与周期 | 月/季、年、月或季度 |
| 2 | 参与范围 | 范围包列表 + 组织树 + 筛选人员列表 |
| 3 | 开放时间 | 启动、员工截止、上级评分截止 |
| 4 | 模板匹配 | 范围包 ↔ 模板下拉；预览人数 |
| 5 | 确认发放 | 各包汇总；勾选 → **发放选中**；未勾选仅保存 |

---

## 4. 计划详情 · 补发

- 展示 **范围包列表**（名称、人数、模板、发放状态）
- **+ 新增范围**：同步骤 2 交互；仅未发放包可编辑人选
- 对已配置模板但未发的包：**发放待办**
- 员工明细表增加 **所属范围包** 列

---

## 5. 花名册字段

| 字段 | 用途 |
|------|------|
| 人群类型 | 树/列表 **展示**；不参与自动模板匹配 |
| 职级 | 选人 **筛选** |
| 岗位名称 | 选人 **关键字搜索** |
