# GRILL · 考核三级结构定稿

> **日期**：2026-06-03 · **状态**：已确认  
> **关联**：[GRILL_V1.3.md](./GRILL_V1.3.md) · [FORM_TEMPLATE_ANALYSIS.md](./FORM_TEMPLATE_ANALYSIS.md)

## 结构

```
一级 · 核心 V / 常规 X（月度 Step1/2；季度 Step1/2）
  └ 二级 · 关键目标：O（本区块仅填 1 份）
       └ 三级 · 考核目标：SMART + KR权重 + 考核标准（分档）+ 关键成果 M + 自评

下月/下季（固定一级「下月/下季核心目标」，不可新增一级）
  └ 二级 · 关键目标：O（1 份）
       └ 三级 · 考核目标：SMART + 权重 + 标准 + M（无自评；可填挑战/资源）
```

## 权重

| 场景 | 规则 |
|------|------|
| 月度本周期 | 核心+常规 **全部三级 KR 权重 = 85%**（二者任意拆分）；行为 15% 独立 |
| 季度本周期 | 核心+常规 **全部三级 KR 权重 = 90%**；无行为步；6Q3J 另计 |
| 下月/下季 | 整段三级 KR 权重 **= 100%**；软规划但提交硬校验 |

未达标 → 提交拦截 + 步骤条 Step1/2/5/6（及季度对应步）**红色高亮**。

## 评分与展示

- **上级**：仅对**三级**逐项打上级分；二级只读分组
- **分管（月度 v1.3）**：待我审核 **改核定总分**（全表覆盖，不逐项）
- **分管（季度）**：与上级可评项一致 **逐项** + 可选 **改总分**；见 [GRILL_DIVISION_SCORING.md](./GRILL_DIVISION_SCORING.md)
- **各端一致**：填表 / 领导评 / HR 详情 / 确认页 / 季度页 — 同一套 L1→L2→L3 折叠树

## 默认预置

- 核心/常规各默认 **1 个关键目标 + 2 个考核目标**，带模板样例；可「+ 增加关键目标」
- 每个关键目标展示其下考核目标**权重小计**；顶部权重条为全区合计
- 增删：「+ 增加关键目标」「+ 增加考核目标」；至少保留 1 关键目标、每关键目标至少 1 考核目标

## 数据模型（原型）

```javascript
coreKeyObjectives: [{ id, o, targets: [{ id, smart, weight, standardTiers, m, selfScore }] }]
regularKeyObjectives: [...]
nextMonthKeyObjectives: [...]  // targets 无 selfScore，可有 challenge
```

兼容：旧 `coreKrs[]` 扁平数组在 `loadState` 时自动迁移为「每条 → 1 关键目标 + 1 考核目标」。
