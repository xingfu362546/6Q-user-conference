## 3. 入口与信息架构

### 3.1 小程序

- **首页 · 自助服务 ·「绩效」宫格**（**不改**底栏「我的」）
- 模块首屏 **双 Tab**：
  - **【员工】我的待办** → 子 Tab：`当前待办 | 逾期 | 过往提交`
  - **【领导】待我审核** → 下属待评 → 评分页（批量评 **仅 OA**）

### 3.2 OA-PC 个人中心

- **个人中心 → 绩效**（与小程序 **同构双 Tab**）
- HR：**人力资源 → 绩效管理 → 计划管理**（非个人中心）

### 3.3 任务可见性（员工）

| 子 Tab | 规则 |
|--------|------|
| 当前待办 | 计划执行中、**未过截止** |
| 逾期 | 过截止未交；HR 解锁后可回当前待办 **断点续填** |
| 过往提交 | 已提交；**可回看本人填写**（KR、自评、自评分）；❌ **不可见上级评分/评语/综合结果**（保密） |

---

## 4. 填表向导

### 4.1 月度（8 子步 · 三大段）

**制定目标**：①核心V ②常规X ③行为态度(模板固定) ④加减分  
**自评**：⑤打分(M+自评分) ⑥总结  
**下月·提交**：⑦下月目标(3–4项, **提交必填**) ⑧确认提交  

- 同任务一次提交；**多页 + 步骤条**；草稿同步  
- **复制上月**：按钮/轻提示，不静默；有内容需确认  
- 当月内可填 KR，**不强制月初**  
- MVP 目标：**员工手填 KR**；项目系统导入 → 二期  

### 4.2 季度（~10–11 步 · 同三大段框架）

工作 KR(90%) → **6Q3J 只读导入** → 加减分(含人才部核定列) → **表内面谈** → 自评 → **下季目标 2–3 项** → 提交  

### 4.3 退回 / 解锁

- **退回**：向导 **断点** 修改，不作废重提；展示退回原因与历史  
- **HR 解锁**：回当前待办，**断点续填**

## 5. 评分权限与保密

| 角色 | 可填分 |
|------|--------|
| 员工本人 | 自评、加减分申报与自评加减分 |
| 直接上级 | 上级评分、核定加减分 |
| 总经理 | 完整流程启用后（可选非必须） |
| **其他** | ❌ 无待办、不可评 |

**员工保密**：❌ 不可查看 **上级对自己的评分** 及衍生综合结果/评语。
