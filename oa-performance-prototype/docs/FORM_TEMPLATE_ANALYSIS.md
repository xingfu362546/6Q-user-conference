## 0. 总览：两种考核表 + 批次计划

| 类型 | 模板 Sheet（V1.2 主用） | 周期 | 员工动作 |
|------|-------------------------|------|----------|
| **月度绩效** | 总监/经理；主管/职员 | 每月 | 按表填写当月 KR、自评、下月目标等 |
| **季度绩效** | 副总/总监/经理；主管/职员 | 每季 | 按表填写当季 KR、6Q3J、加减分、面谈、下季目标 |

**任务发放（你补充的业务规则）**：

系统用 **「考核计划 / 批次」** 管理每次填写任务：

1. **自动生成**：后台按周期规则（如每月 1 日、每季末）自动生成计划并 **发放** 到员工待办。  
2. **HR 手工创建**：HR 创建计划 → 选考核类型（月/季）→ 选参与范围 → 设 **开放时间** → 手动/定时 **发放**。

员工端只看到：**当前批次下的一张表**（状态：未开始 / 填写中 / 已提交 / …）。

## 一、月度绩效表（表1）

### 1.1 适用 Sheet

- `月度绩效V1.2版-（总监 经理）` — 工作 KR **4–6 项**
- `月度绩效V1.2版-（主管 职员）` — 工作 KR **2–4 项**

### 1.2 页面分区

```
┌─ 表头（只读：姓名/部门/岗位/评价人/考核期/填写日期） ─┐
├─ 【A】本月工作关键结果考评 ─────────────────────────────┤
│    ├ 核心绩效 V%      （多行 KR，B 列合并）              │
│    ├ 常规绩效 X%      （多行 KR，V+X=85%）               │
│    ├ 行为态度 15%     （模板固定 ~4 项，不可增删）        │
│    └ 加减分           （加分/减分行）                    │
│    合计 + 签名 + 领导评定                              │
├─ 【B】下月核心工作目标（3–4 项，无评分列）               │
└────────────────────────────────────────────────────────┘
```

### 1.3 【A】区字段（列）

| 字段 | 目标制定 | 自评 | 上级评 |
|------|---------|------|--------|
| 关键目标 O | ✍️ | 👁 | 👁 |
| 考核目标 SMART | ✍️ | 👁 | 👁 |
| KR 权重（合计 100%） | ✍️ | 👁 | 👁 |
| 考核标准 | ✍️/模板 | 👁 | 👁 |
| 关键成果 M | — | ✍️ | 👁 |
| 自评分 / 上级评分 / 综合得分 | — | ✍️ / — / 自动 | — / ✍️ / 自动 |

- **行级综合分** = 自评×20% + 上级×80%  
- **指标类型**：按 **区块** 区分（非每行下拉），见 #3 结论  
- **续行**：同区块第 2+ 行可只填权重、关键成果、分数（O/SMART/标准沿用首行或留空）

### 1.4 【B】下月区字段

| 字段 | 说明 |
|------|------|
| O / SMART / KR权重 / 考核标准 | 同本月 |
| **存在挑战/需求资源** | 下月特有 |
| 备注 | 可选 |
| ❌ 无自评/上级/综合分 | |

## 二、季度绩效表（表2）

### 2.1 适用 Sheet

- `季度绩效（副总经理 总监 经理)V1.2-已调整`
- `季度绩效（主管 职员)V1.2-已调整`

### 2.2 与月度的关键差异

| 维度 | 月度 | 季度 |
|------|------|------|
| 工作 KR 权重合计 | V+X=**85%** + 行为态度 **15%** | 工作块 KR 权重 **90%** |
| 行为态度 | 表内固定 4 项 | **无**独立 15% 行为块（融入其他设计） |
| 评分人 | 自评 + **上级** | 自评 + **上级** + **分管领导** |
| 工作块公式 | 自评 20% + 上级 80% | **自评 20% + 上级 40% + 分管 40%** |
| **6Q3J 人才评价** | 无 | **10 分**（1368 认证 4 + 文化经句 3 + AI 提效 3，**客观分导入**） |
| 加减分 | 表内即时计入 | 季度收集；**人才开发部核定得分**列；应用于年度 |
| 绩效面谈 | 清单独立功能 | **表内嵌**（亮点/待提升/改进计划） |
| 下期目标 | 下月核心 **3–4 项** | 下季核心 **2–3 项**；含「关键成果 M（预估）」 |

### 2.3 季度表分区

```
┌─ 表头（+公司字段） ─────────────────────────────────────┐
├─ 【A】本季度工作 KR（核心 V + 常规 X，权重合计 90%）     │
│    列：O / SMART / 权重 / 考核标准 / M / 自评 / 上级 / 分管 / 得分 │
├─ 【B】6Q3J 人才评价（10 分，三项客观分 + 总分）          │
├─ 【C】加减分项（含人才开发部核定得分）                   │
├─ 【D】核定总分、总经理评定、签名                         │
├─ 【E】绩效面谈记录（四段文本）                           │
└─ 【F】下季度核心目标（2–3 项 + 考核标准 + M预估）        │
```

### 2.4 前端注意点

- 季度表 **多一列「分管领导评分」**，上级评分页需三列对照（清单 #23/#24）。  
- 6Q3J 三块分数 **只读**，来自 HR/外部系统导入（清单 #35）。  
- 加减分 **O 列「人才开发部核定得分」** 仅 HR 可写。

## 三、#3 指标权重 · 最终结论（据官方月表）

采用 **固定四区块**（核心 V / 常规 X / 行为态度 15% / 加减分），员工在 V、X 区块内 **添加 KR 行**；行为态度为 **模板预置项**；底部 **100% 进度条** 校验。
