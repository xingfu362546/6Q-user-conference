# 上级评分 · 双端规格（v1.0.0 · 已确认）

> Grill 对齐日期：2026-06-03 · 关联：`docs/HANDOFF-v1.0.0.md` §4.3

## 待办触达

- 直接上级在 **OA 待办** 与 **小程序待办** 均可收到「下属绩效待评」
- 分管领导 **默认仅 OA** 收到「待分管评」
- 仅 **本人 | 直接上级 | 总经理 | 分管领导（季度）** 有评分待办

## 打分刻度

- 上级直接填 **加权分**（0 ~ **权重×100 的百分值即权重本身**，例：权重 25% → 上限 **25 分**）

## 校验规则

| 规则 | 行为 |
|------|------|
| R1 | 单项上级分 > 权重 → 该项变红 |
| R2a | **核心 V 区块合计 > 85** → 红字「已超过上限 85 分」 |
| R2b | **常规 X 区块合计 > 15** → 红字 |
| R2c | **行为态度区块合计 > 15** → 红字 |
| R2d | 工作块 V+X+行为 **合计 > 100** → 汇总红字 |
| R3 | 加减分超事项库上限 → 该行变红 |
| 预览 | **工作块小计 + 加减分 = 核定总分** |

## 页面内容与上级动作

| 区块 | 上级操作 |
|------|----------|
| 本月/本季 KR + 行为态度 | **填上级分** |
| 加减分 | **核定**（可改分） |
| 自评总结 | 只读（Tab 对照） |
| 下月/下季目标 | **确认 / 退回**（**不打分**） |
| 季度 6Q3J / 面谈 | 只读 |

**标准动作集**：KR 分 + 行为分 + 加减分核定 + 下月目标确认/退回 + 整表退回 + 评语选填 + 提交

## 双端分工

| 能力 | OA-PC | 小程序 |
|------|-------|--------|
| 待评下属列表 | ✅ | ✅（领导 Tab） |
| 月度单人完整评分 | ✅ | ✅ 简版 |
| 季度上级评 | 🔲 占位 | 🔲 待做 |
| 季度分管评 | 🔲 占位 | ❌ |
| 上级=分管同人 | 1 待办，填一次两列同值 | 同左 |
| 批量同指标 #26 | 后续迭代 | ❌ |
| 布局 | 上方折叠卡片打分，下方 Tab 员工原文 | 折叠卡片 |
| 导航 | 列表 → 评分 → **提交回列表** | 同左 |
| 草稿 | 离开时有改动 → **保存草稿 / 放弃** | 简化 confirm |

## 保密

员工端 **不可见** 上级评分、评语、综合核定结果。
