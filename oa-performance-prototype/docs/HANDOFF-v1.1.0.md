## 状态机（待办粗粒度）

```
填写中 → 待上级评 → 待分管评 → 待确认 → 已完成
```

- 计划字段：`confirmDeadline`（与员工/上级共用）  
- 超时：催办；未双方确认 → 不结算奖金、不归档  
- 退回：确认完成前均可；断点续改、数据保留
