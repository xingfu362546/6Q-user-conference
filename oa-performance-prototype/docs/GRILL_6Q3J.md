# 季度 6Q3J 客观分 · HR 计划导入 · 需求规格

> **日期**：2026-06-03  
> **状态**：Grill 已确认 · **v1.2 原型已实现（演示）**  
> **关联**：`quarterly-wizard.html`、`supervisor-score-quarterly.html`、`hr-plan-detail.html`、功能清单 #35

---

## 1. 业务背景

季度绩效表 **6Q3J 人才评价**（约 10 分）含三项**客观分**，不由员工自填、不由上级主观打：

| 分项 | 典型上限 | 数据来源（业务） |
|------|----------|------------------|
| **1368 认证** | 4 或 6 分（随模板/职级） | 1368 项目组统计 |
| **文化经句践行** | 2–4 分 | 文化经句项目组折算，人才开发部汇总 |
| **AI 提效应用** | 2–4 分 | 人才开发部 / 待定口径 |

HR 在 **考核计划** 内通过 Excel 导入写入各员工任务；员工 / 上级 **只读** 查看（与 `DATA_SYNC.md` 一致）。

---

## 2. Grill 决策（2026-06-03）

| # | 议题 | 决策 |
|---|------|------|
| Q1 | 三项导入粒度 | **分项独立**：每项单独「待导入」或显示分值；到达时间可不同 |
| Q2 | 员工提交季表 | **不拦截**：6Q3J 未齐仍可 Step7 提交；分后补并重算综合总分 |
| Q3 | 6Q3J 总分展示 | **已导入项求和 + 标注缺项**，如 `6.5 / 10 · AI 提效 待导入` |
| Q4 | HR 导入入口 | **计划明细**统一入口 + **Excel 三列**（1368 / 文化经句 / AI），可分批只导部分列 |
| Q5 | 覆盖改分 | **未双方确认**：静默重算；**已双方确认**：允许覆盖但 phase→`pending_confirm`，需重新确认（对齐 v1.1 HR 改分） |
| Q6 | 文案 | 6Q3J 缺项 → **「待导入」**；奖金侧 → **「待结算」+ 阻塞原因**（二者不混用） |
| Q7 | 奖金排名联动 | **本版本（v1.2 演示）不开发**；不做「6Q3J 未齐 → 阻塞奖金排名」等引擎逻辑 |
| Q8 | 各端可见性 | **员工 / 上级 / HR 三端一致**展示分项状态与分值 |
| Q9 | 导入分值校验 | **原型演示不校验上限**（mock 任意合理分）；**正式环境**按员工模板/职级逐项上限校验（超上限整行失败） |

## 3. v1.2 原型演示范围（In Scope）

| 模块 | 演示内容 |
|------|----------|
| **HR · 计划明细** | 「导入 6Q3J」入口；mock 上传 / 选文件；按工号写入三项分（可只填部分列） |
| **员工 · 季度填表 Step3** | 三项只读：有分显示 `x / 上限`；无分显示 **待导入**；6Q3J 小计按 Q3 规则 |
| **上级 · 季度评分页** | 6Q3J 区块只读，状态与员工端同源（同 `taskId`） |
| **数据** | `sixQ3J: { cert, culture, ai }` 缺省 `null` → 待导入；写入后双端同步 |

## 4. v1.2 明确不做（Out of Scope）

| 项 | 说明 |
|----|------|
| **6Q3J ↔ 奖金排名** | 不实现「6Q3J 未齐则不参与排名」；现有奖金试算逻辑**不与 6Q3J 联动** |
| **综合总分自动重算引擎** | 演示可 alert / 静态 mock；不做完整后端重算与通知 |
| **导入上限校验** | 演示不校验职级/template 上限（Q9-C） |
| **独立菜单「6Q3J 导入」** | 入口仅在计划明细（Q4） |
| **三项分系统对接** | 不对接 1368 / 文化经句 / AI 外部系统 API |

> 后续版本再定：6Q3J 齐项后纳入综合总分 → 奖金硬阻塞/重算（参见 Q7 备注）。

## 5. 展示与文案规范

### 5.1 分项

```
有分：  1368 认证    4.00 / 4 分
无分：  文化经句践行  待导入
```

### 5.2 6Q3J 总分（部分导入）

```
6Q3J 总分    6.50 / 10    AI 提效应用 待导入
```

### 5.3 与「待结算」区分

| 用语 | 场景 |
|------|------|
| **待导入** | HR 尚未导入 6Q3J 某项/全部客观分 |
| **待结算** | 奖金试算：待上级评 / 待分管评 / 未双方确认等（**不含** 6Q3J 逻辑，本版） |

## 6. 数据模型（草案）

```json
{
  "sixQ3J": {
    "cert": 4.0,
    "culture": null,
    "ai": 2.5,
    "importedAt": {
      "cert": "2026-06-15T10:00:00Z",
      "culture": null,
      "ai": "2026-06-20T14:00:00Z"
    }
  }
}
```

- `null` → 前端渲染 **待导入**
- 导入 API / mock：支持**按列 upsert**（只更新 Excel 中有值的列）
- 覆盖规则见 Q5
