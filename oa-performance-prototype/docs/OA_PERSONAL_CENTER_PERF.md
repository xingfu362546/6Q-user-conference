# OA-PC · 个人中心 · 绩效（草案）

> 员工填表、上级评分均从 **个人中心** 进入；**Tab 区分角色视角**（用户明确要求标注）。

## 入口结构

```
个人中心
└─ 绩效（一个菜单项，内部分 Tab）
     ├─ Tab 【员工】我的待办      ← 我作为被考核人需填写/提交的任务
     └─ Tab 【领导】待我审核      ← 我作为上级需评分/审核的下属任务
```

> 命名可微调，但须 **一眼区分**「我是员工」vs「我是领导」。

## Tab · 【员工】我的待办

| 项 | 说明 |
|----|------|
| 等同原「绩效任务」 | 任务列表：当前待办 / 过往待办 |
| 点击 | 填表向导（月/季，与小程序同源 taskId） |
| 规则 | 未过截止才在当前待办；逾期进过往 |

## Tab · 【领导】待我审核

| 项 | 说明 |
|----|------|
| 列表 | 下属姓名、部门、考核期、类型、状态（待评/已评） |
| 点击 | 评分页（单人完整表；OA 宽表 + 批量能力见 `OA_SUPERVISOR_SCORING.md`） |
| 权限 | 仅 **直接上级**（及后续流程中的总经理）有单；**无待办则 Tab 可空态** |
| 标注 | Tab 标题/副标题标明 **「领导 · 待我审核」**，避免与员工待办混淆 |

## 双角色用户

同一人既是员工又是上级时：
- **同一「绩效」入口**，默认 Tab 可记上次停留或 **待办数角标** 分 Tab 展示（如 员工(1) | 领导(3)）
- 两类 taskId **不同**（我的考核 vs 下属的考核），不可混列表

## 与 HR 菜单

| 角色 | 路径 |
|------|------|
| 员工/上级 | 个人中心 → 绩效（双 Tab） |
| HR | 人力资源 → 绩效管理 → 计划管理 |

## 小程序（已确认 A）

首页宫格「绩效」→ 模块首屏 **双 Tab**（与 OA-PC 一致）：

| Tab | 说明 |
|-----|------|
| **【员工】我的待办** | 子 Tab：**当前待办 \| 逾期 \| 过往提交**（无上级评分，保密） |
| **【领导】待我审核** | 下属待评 → 评分页 |

- **不改** 小程序底栏「我的」
- 上级批量评 (#26) 仍 **仅 OA 宽表**
