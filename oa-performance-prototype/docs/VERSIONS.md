## v1.1.0 变更摘要

1. **评分确认**：上级+分管评完后进入「待确认」；计划增加确认截止；双方确认前阻塞奖金结算  
2. **分管评分列**：OA/小程序领导评分页增加分管录入（同人合并一次录入）  
3. **下月目标去重**：领导评分页去掉重复下月目标区块  
4. **小程序 v1**：员工不看填表入口，只看进度+确认；领导 Tab 可评+可确认  
5. **退回至员工**：确认完成前 HR/上级可退，数据保留断点续改  
6. **人员绩效结果明细**：HR 全量 + 部门负责人本部门；仅总得分，不含奖金排名；菜单按系统权限  
7. **奖金规则**：按职级配置，同职级不可重复启用（v1.0.1 补丁已含）
