## v1.4.0 变更摘要

> 详见 [GRILL_WORKFLOW.md](./GRILL_WORKFLOW.md)

1. **月/季分轨**：月度 5 步（无待分管）；季度 6 步（同人合并跳过待分管）
2. **月度进待确认**：上级提交即可，不等分管核定
3. **已确认终态**：月=员工+上级；季=+分管；`confirmed` 替代 `completed`
4. **改核定总分**：全 ✓ 前可改；改分仅清零已确认方；全 ✓ 后按钮 disabled
5. **确认页**：三分 badge；季度分管可确认（`?type=quarter&role=division`）
6. **列表/筛选**：待填写 `not_started`；HR 确认态列走 `renderConfirmBadges`

## v1.3.0 变更摘要

> 详见 [GRILL_V1.3.md](./GRILL_V1.3.md)

1. **分管改总分**：部门待办直接改核定总分，标记「分管已调整」→ 待确认  
2. **评分确认页**：模块表格（自评|上级评）+ 折算汇总  
3. **HR 详情**：系统汇总→分管核定完整对比  
4. **填表**：V/X/下月·下季统一「考核目标」，支持多个目标  
5. **排序**：待我审核、部门待办按自评总分高→低  
6. **导出**：汇总 Sheet 列占位「模板待确认」  
7. **原型注释**：`.proto-ver--old` / `.proto-ver--new` 标注版本差异  

## v1.2.0 变更摘要（原型演示）

> 详见 [GRILL_6Q3J.md](./GRILL_6Q3J.md)

1. **6Q3J 三项客观分**：1368 / 文化经句 / AI 提效 — HR 在**季度计划明细** CSV 导入，分项独立、可分批  
2. **展示**：未导入 → **「待导入」**；已导入 → 分值；总分 = 已导入求和 + 标注缺项  
3. **三端同步**：`perf-sixq3j.js` · 员工季表 Step3、上级季度评分、HR 列表 6Q3J 列  
4. **本版本不做**：6Q3J ↔ 奖金排名；导入上限校验  
5. **演示**：`hr-plan-detail?plan=2026-Q2` → 导入 → 刷新季表/上级评页

## v1.1.1 变更摘要

1. **填表步骤精简**：月度 8→6 步、季度 9→7 步；核心/常规 KR 填完关键成果后**同页自评**；取消独立「自评打分」「加减分」步，加减分合并至行为步底部  
2. **领导待审列表**：增加「自评总分」列（Σ KR 自评 + 行为自评 + 加减分申报），供评分前参考  
3. **计划明细批量转办**：勾选多条员工任务 → 组织架构选人 → 更新处理人列  
4. **评分配两位小数**：自评、上级、分管录入最多 2 位小数；整数统一展示 `x.00`（`perf-score-format.js` 全链路接入）  
5. **HR 待办详情改分**：计划内入口 + HR 权限，待确认态可修改上级分并重算总分（改分后需双方重新确认）

## v1.1.0 变更摘要

1. **评分确认**：上级+分管评完后进入「待确认」；计划增加确认截止；双方确认前阻塞奖金结算  
2. **分管评分列**：OA/小程序领导评分页增加分管录入（同人合并一次录入）  
3. **下月目标去重**：领导评分页去掉重复下月目标区块  
4. **小程序 v1**：员工不看填表入口，只看进度+确认；领导 Tab 可评+可确认  
5. **退回至员工**：确认完成前 HR/上级可退，数据保留断点续改  
6. **人员绩效结果明细**：HR 全量 + 部门负责人本部门；仅总得分，不含奖金排名；菜单按系统权限  
7. **奖金规则**：按职级配置，同职级不可重复启用（v1.0.1 补丁已含）
