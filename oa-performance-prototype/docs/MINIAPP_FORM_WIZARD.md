# 月度填表 · 多页步骤向导

> 用户确认：单任务一次提交（#5-A），UI 拆多页 + 顶部步骤条。  
> **原型**：`prototype/miniapp/monthly-wizard.html` · `prototype/oa-pc/monthly-wizard.html`

> 用户确认：单任务一次提交（#5-A），UI 拆多页 + 顶部步骤条。

## 导航结构

```
任务列表 → 点击月度任务
  └─ 填表向导（Stepper 固定顶栏）
        Step 1  核心绩效 V%
        Step 2  常规绩效 X%
        Step 3  行为态度 15%
        Step 4  加减分
        Step 5  自评打分（M + 自评分 + 预览）
        Step 6  自评总结
        Step 7  下月核心目标（必填，#4-A）
        Step 8  确认提交
```

## 交互规则

| 规则 | 说明 |
|------|------|
| 草稿 | 每步 Next 时保存；退出可从最近步骤恢复 |
| 校验 | 当前步通过才允许 Next（权重、必填） |
| 回退 | 可点步骤条回到已完成步骤修改（未提交且未过截止） |
| 一步一页 | 核心 / 常规 **分两个页面**（用户明确要求） |
| 提交 | 仅 Step8；校验含下月目标 + 权重 100% |

## 步骤条样式（已确认 B）

**三大段 + 子步 1→8**：

```
[ 制定目标 ]     [ 自评 ]        [ 下月·提交 ]
  ①核心V           ⑤自评打分       ⑦下月目标
  ②常规X           ⑥自评总结       ⑧确认提交
  ③行为态度
  ④加减分
```

顶栏展示：当前主阶段名 + 子步序号（如 自评 · 5/8）。

## HR 解锁 (#41)

- 截止后任务在 **过往待办** 显示「已逾期」
- HR **解锁** 指定员工任务后 → 回到 **当前待办**
- 员工进入向导 **从断点步骤继续**（草稿与已完成步骤保留）

## 季度表 · 步骤（已确认 A）

与月度相同 **三大段** 框架，段内约 **10–11 步**（待写逐步清单）：

1. 核心 V / 常规 X（工作 KR 合计 90%）
2. **6Q3J**（只读，系统导入）
3. 加减分
4. **绩效面谈**（表内四段文本）
5. 自评打分 / 总结
6. **下季核心目标** 2–3 项
7. 确认提交

**数据**：与 OA-PC、上级评分端 **同一 taskId**（`DATA_SYNC.md`）。

## 小程序 UX 注意

- 顶栏：返回列表 + 周期标题 + 步骤进度（如 3/8）
- 长表单用 **卡片列表 + 底部「添加指标」**，避免单页过长
- 行为态度：只读模板行 + 关键事件输入
