## MVP 三页说明

### 1. 计划列表

| 列（建议） | 说明 |
|------------|------|
| 计划名称 | 如「2026年5月月度考核」 |
| 考核类型 | 月度 / 季度 |
| 考核周期 | 2026-05 / 2026-Q2 |
| 参与范围 | N 个范围包 · M 人（分批发放） |
| 状态 | 草稿 / 已发放 / 进行中 / 已截止 / 已锁定 |
| 启动~截止 | 时间窗 |
| 进度 | 已提交/总人数 |
| 操作 | 编辑(草稿) / 发放 / 明细 / 催办 / 解锁 |

**约束**：同周期唯一（年+月 或 年+季度）。

### 2. 新建计划向导

1. 考核类型（月/季）+ 周期（校验唯一）
2. **参与范围**：范围包 + 全集团组织树（职级/岗位筛选；详见 `GRILL_HR_SCOPE.md`）
3. 时间：启动、员工截止、上级评分截止
4. **模板匹配**：每个范围包手动选一张模板
5. **确认发放**：勾选要发的范围包 → 发放选中（可后续在明细补发）

### 3. 计划明细

- 筛选：**主要组织（部门）**、岗位、职级、任务状态
- 列：员工姓名、工号、部门、状态、提交时间、综合得分…
- 操作：催办 (#39)、退回 (#40)、解锁 (#41)、导出 (#43)
- HR 负责人 **统计** 入口：汇总本计划已完成数据（#42）
