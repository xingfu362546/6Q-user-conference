## 2. 产品范围（v1.0.0）

### 2.1 人群与模板

- 花名册 **人群类型**：仅 **全职员工**、**办事处**（展示用，不参与自动模板匹配）
- **模板匹配**：按 **范围包 → 一张模板**（HR 手动绑定，见 `docs/GRILL_HR_SCOPE.md`）
- 考核类型：**月度**、**季度**

### 2.2 计划与发放

- HR **手工创建**考核计划；全公司周期 **唯一**（年+月 / 年+季度）
- **参与范围 = 范围包**：组织树勾选 + 职级/岗位筛选；一人仅属一包；未分配者不参与
- **分批发放**：每范围包可单独发放；已发放锁定；详情页可新建范围包补发
- **奖金规则**：按 **职级** 配置奖扣档；**同职级不可重复启用**；计划按职级自动匹配；**上级+分管领导均评完**后实时结算；**仅 HR/薪酬可见**（见 GRILL_BONUS_RULES）
- 计划级时间：启动、员工截止、上级评分截止

### 2.3 双端矩阵

| 端 | 角色 | 入口 |
|----|------|------|
| **小程序（6Q教育）** | 员工、直接上级 | 首页宫格「绩效」 |
| **OA-PC** | 员工、直接上级、HR | 个人中心 / 人力资源 |

### 2.4 保密

- 员工 **不可见** 上级评分、评语、综合核定结果
- 过往提交：仅回看 **本人填写** + 状态

## 4. 上级评分 · Grill 决策摘要（v1.0.0 锁定）

| # | 决策 |
|---|------|
| 1 | 刻度 **A**：直接填加权分，0 ~ 权重 |
| 2 | 展示 **C**：评分相关全展示；下月目标同页 **不打分** |
| 3 | 动作 **B**：KR+行为+加减分核定+下月确认/退回+整表退回；评语选填 |
| 4 | 校验 **A**：R1 单项 + R2 合计100 + R3 加减分；超限变红不可提交 |
| 5 | 范围 **C**：月度 + 季度全角色（季表原型占位） |
| 6 | 双端 **B**：OA 完整 + 小程序简版 |
| 7 | 分管 **D**：分管默认仅 OA；上级=分管 → 1 待办填一次两列同值 |
| 8 | 布局 **C**：轻量；上方折叠卡片打分，下方 Tab 员工原文 |
| 9 | 导航 **A**：列表↔评分↔提交回列表 |
| 10 | 草稿 **C**：离开时有改动 → 保存草稿/放弃 |
