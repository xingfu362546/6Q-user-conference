# 绩效模块功能清单 V1.0

本期给开发对照的清单不在本文件。v1.5.0 / v1.5.1 按领袖营功能清单的表重排在 [prototype/feature-list.html](prototype/feature-list.html)。下面仍是 2026-05-26 人才开发部的历史条目。

规格目录见该页顶部。正本在本仓库 `specs/001-perf-next-batch/`。

### 1. [1] 考核者（员工）端 / 目标制定 / 月度指标制定

**功能**：考核者在月初设定本月关键目标（O），填写SMART考核目标、KR权重、考核标准。总监/经理版支持4-6项核心指标，主管/职员版支持2-4项，以管理员配置的上下限为准，不得少于下限，多于上限，系统限制不在范围内进行提醒。

### 2. [2] 考核者（员工）端 / 目标制定 / 上月指标一键带入

**功能**：点击「带入上月指标」，上月全部指标（O/KR权重/考核标准）自动复制到本月表单，考核者只需修改变化部分，可对每条指标执行保留/修改/删除操作。

### 3. [3] 考核者（员工）端 / 目标制定 / 指标权重分配

**功能**：核心绩效指标(V%) + 常规绩效指标(X%) = 85%，行为态度固定15%。系统实时显示权重合计进度条，合计≠100%时红色警告，各项权重建议不低于10%。
大类不可调整比例，由管理员配置，每项指标的权重由考核者进行合理分配。

### 4. [4] 考核者（员工）端 / 目标制定 / 下月目标智能预填

**功能**：本月提交后，系统自动将本月的O和KR权重预填到下月目标区，考核者只需确认保留/修改/删除即可。支持3-4项聚焦关键目标，每项需标注权重。

### 5. [6] 考核者（员工）端 / 绩效自评 / 自评评分填写

**功能**：考核者对照评分标准填写每项指标的自评分。每项评分不得超过该指标权重上限（权重%×100分）；超过上限时输入框变红且无法提交。

### 6. [7] 考核者（员工）端 / 绩效自评 / 行为态度评价

**功能**：固定15%行为态度指标，包括团队合作、责任心、主动性等维度。考核者填写自评分并备注关键事件，由上级及人才资源管理部门进行评分。

### 7. [8] 考核者（员工）端 / 绩效自评 / 综合得分预览

**功能**：自评完成后实时显示综合得分预览（自评小计、各项加权分、总分），提交前可自查。月度公式：综合得分=自评分合计×20%+上级评分合计×80%。

### 8. [9] 考核者（员工）端 / 绩效自评 / 自评总结

**功能**：考核者填写本期绩效总结，回顾完成情况、亮点及不足。支持多行文本输入和排版。

### 9. [10] 考核者（员工）端 / 加减分管理 / 加减分事项申报

**功能**：1.考核者填写加减分事项：加分项（特殊价值贡献-主动承担额外任务/效率提升/跨部门攻坚）+减分项（差错与失误-数据错误/流程遗漏/客诉/违规）。结构化录入：事项类型下拉选择+具体描述模板（时间+事件+结果+影响范围）。
2.从加减分管理库中选择事项进行填写。
**人才开发部反馈**：加减分事项需要增加设定评价人可填写

### 10. [11] 考核者（员工）端 / 加减分管理 / 加减分佐证上传

**功能**：支持上传加减分佐证材料（文件/图片），上级审核时参考。确保加减分有据可查，减少退回。

### 11. [12] 考核者（员工）端 / 提交流程 / 月度数表单提交

**功能**：考核者填写完成后提交表单，系统自动校验：权重合计=100%、评分不超过上限、必填字段完整。校验不通过则提示具体错误项且无法提交。
**备注**：需要提交流程
**人才开发部反馈**：默认经理级以上上级评分，如果上级休假，需要转换评价人，应有个选择评价人功能

### 12. [13] 考核者（员工）端 / 提交流程 / 季度绩效考核提交

**功能**：季度考核引入分管领导评分角色。季度末考核者完成自评提交后，流转至上级评分→分管评分。
**备注**：需要提交流程
**人才开发部反馈**：默认经理级以上上级评分，如果上级休假，需要转换评价人，应有个选择评价人功能

### 13. [-] 考核者（员工）端 / 提交流程 / 年度绩效考核提交

**功能**：季度考核引入分管领导评分角色。季度末考核者完成自评提交后，流转至上级评分→分管评分。
**备注**：需要提交流程

### 14. [14] 考核者（员工）端 / 提交流程 / 被退回后修订

**功能**：绩效管理员/上级退回表单时填写退回原因，考核者收到通知后根据意见修订并重新提交。支持查看退回历史记录。
**备注**：退回流程退至考核者后，是否需要重新走流程？
**人才开发部反馈**：退回考核者后，优先重新在修改基础上再提交流转，不用作废重走流程

### 15. [15] 考核者（员工）端 / 提交流程 / 提交截止提醒

**功能**：每月VV日自动推送填写提醒（系统内通知，由管理员设置的考核启动时间为准），截止前VV天每日提醒。超时未提交自动标记逾期。管理员可配置提醒时间和频率。

### 16. [16] 考核者（员工）端 / 结果查询 / 考核结果查看

**功能**：考核者查看本人月度/季度/年度考核结果：各项得分、综合得分、等级评定、上级评语、绩效面谈记录。支持查看近12个月的历史考核结果。
**人才开发部反馈**：员工可查询/导出个人历史分数统计数据

### 17. [18] 考核者（员工）端 / 绩效面谈 / 绩效面谈记录

**功能**：考核者与上级共同填写面谈记录：工作亮点、待提升项、改进计划、意见建议。双方在线电子确认（签字/勾选）。

### 18. [19] 考核者（员工）端 / 绩效面谈 / 绩效改进计划

**功能**：基于面谈结果制定下阶段改进计划，明确改进目标、行动步骤、时间节点和目标。计划自动关联下月考核指标。

### 19. [20] 绩效评价者（上级）端 / 部门OGSM管理 / OGSM维护与拆解

**功能**：部门负责人管理本部门OGSM，并拆解至个人，个人在考核端进行确认

### 20. [21] 绩效评价者（上级）端 / 部门OGSM管理 / 每月目标确定

**功能**：上级确认考核者提交的下月3-4项目标，确认后即成为下月绩效考核依据。如需调整，退回至考核者修改。

### 21. [22] 绩效评价者（上级）端 / 绩效评分 / 月度评分（直接上级）

**功能**：上级对下属进行月度绩效评分，包含工作指标评分+行为态度评分+加减分评定。一个页面展示全部下属的评分状态（已提交/待评分/已评分），支持Tab键快速切换评分框。

### 22. [23] 绩效评价者（上级）端 / 绩效评分 / 季度评分（直接上级）

**功能**：上级对下属进行季度绩效评分（自评×20%+上级×40%+分管×40%）。评分时右侧同步展示员工自评内容和自评分，便于对照参考。
**人才开发部反馈**：识别直接上级和分管领导为同一个人时，评分只需要填写一次，将直接上级和分管领导两层评分结果保留一致计算

### 23. [24] 绩效评价者（上级）端 / 绩效评分 / 季度评分（分管领导）

**功能**：分管领导对副总经理及以下人员进行季度分管评分，权重40%。评分页面展示员工自评分和上级评分（只读）作为参考。
**人才开发部反馈**：识别直接上级和分管领导为同一个人时，评分只需要填写一次，将直接上级和分管领导两层评分结果保留一致计算

### 24. [25] 绩效评价者（上级）端 / 绩效评分 / 评分自动汇总

**功能**：上级评分完成后，系统自动按公式计算综合得分（含加减分），实时刷新。零手动计算，杜绝公式错误。

### 25. [26] 绩效评价者（上级）端 / 绩效评分 / 批量快速评分

**功能**：在同一页面内对多个下属的同一指标进行评分，每行一个下属+评分输入框，当前评分行高亮。适合管理10+人的经理/总监。

### 26. [27] 绩效评价者（上级）端 / 绩效评分 / 逾期评分提醒

**功能**：截止日前3天开始提醒上级仍有N人待评分，超时自动标记。统计上级未评人数和姓名。

### 27. [28] 绩效评价者（上级）端 / 面谈与反馈 / 绩效反馈与评语

**功能**：上级填写绩效评语，对下属本期表现进行综合评价。季度/年度考核后需进行绩效反馈面谈。

### 28. [29] 绩效评价者（上级）端 / 面谈与反馈 / 绩效面谈确认

**功能**：上下级共同完成绩效面谈记录并电子确认。支持四段式面谈模板：工作亮点/待提升/改进计划/意见建议。

### 29. [30] 绩效评价者（上级）端 / 面谈与反馈 / 绩效改进审批

**功能**：上级审批下属提交的绩效改进计划，确认或提出调整建议。改进计划完成情况纳入下期考核。

### 30. [32] 管理部门（HR/管理员）端 / 基础配置 / 组织架构与评分关系配置

**功能**：导入组织架构后，系统按部门+职级自动分配考核模板和评分人关系（谁评谁）。支持批量导入/手动调整评分关系；岗位变动自动重新关联。

### 31. [-] 管理部门（HR/管理员）端 / 基础配置 / 考核模板管理

**功能**：管理员按职级配置考核模板：指标数量范围（总监经理4-6项/主管职员2-4项）、核心/常规指标占比（V%+X%=85%）、行为态度固定15%、加减分开关。支持新建/编辑/停用/删除模板。

### 32. [33] 管理部门（HR/管理员）端 / 基础配置 / 考核时间设置

**功能**：管理员设置月度/季度考核时间：启动日期、截止日期、上级评分截止日期。超时不可操作。支持按部门差异化设置。
**人才开发部反馈**：需要单独开放时间可进行修改操作

### 33. [34] 管理部门（HR/管理员）端 / 基础配置 / 考核周期配置

**功能**：配置考核周期类型（月度/季度/年度），每个周期的起止时间、评分公式、参与人员范围。支持灵活开启/关闭某个周期。

### 34. [35] 管理部门（HR/管理员）端 / 基础配置 / 加减分明细库管理

**功能**：维护标准化加减分明细库：16项加分明细（特殊贡献/效率提升/跨部门支撑等）+36项减分明细（9大类-数据错误/流程遗漏/客诉/违规等），含分档阶梯式评分标准。

### 35. [-] 管理部门（HR/管理员）端 / 基础配置 / 6Q3J人才评价指标

**功能**：季度绩效：6Q3J人才评价：1368认证（V分）；文化经句（V分）；AI提效（V分）。
**人才开发部反馈**：6Q3J人才评价客观分数导入功能，自动链接到员工综合分数。

### 36. [37] 管理部门（HR/管理员）端 / 基础配置 / 部门OGSM目标关联

**功能**：考核指标与部门OGSM目标关联。部门目标拆解到个人KPI时，自动代入部门OGSM中的关键目标O。
**备注**：1.0版先不处理

### 37. [38] 管理部门（HR/管理员）端 / 过程管控 / 考核进度总览看板

**功能**：实时查看全公司/各部门的考核进度：未开始/填写中/已提交/已评分/已完成，各状态人数统计。支持按部门树展开，点击数字钻取到具体人员名单。

### 38. [39] 管理部门（HR/管理员）端 / 过程管控 / 逾期未提交催办

**功能**：管理员一键催办逾期未提交/未评分的考核者和评分人。系统自动推送催办通知，支持自定义催办消息内容。

### 39. [40] 管理部门（HR/管理员）端 / 过程管控 / 流程退回管理

**功能**：管理员拥有流程退回权限，可退回任意状态的表单至考核者或评分人。退回时填写原因，退回记录可追溯。

### 40. [41] 管理部门（HR/管理员）端 / 过程管控 / 考核表单锁定与解锁

**功能**：时间窗口关闭后自动锁定表单。管理员可手动解锁特定表单支持特殊场景（延期、补填等），解锁操作需记录日志。

### 41. [42] 管理部门（HR/管理员）端 / 数据与报表 / 绩效考核成绩汇总

**功能**：生成各部门/全公司月度/季度绩效考核成绩汇总表，含各项得分、综合得分、加减分、等级评定。支持按组织架构筛选和多维度统计。

### 42. [43] 管理部门（HR/管理员）端 / 数据与报表 / 批量导出考核数据

**功能**：按组织架构筛选，批量导出员工考核成绩（Excel格式）。可选导出字段：基本信息、各项得分、综合得分、加减分、评语等。

### 43. [44] 管理部门（HR/管理员）端 / 数据与报表 / 考核成绩导入/导出

**功能**：支持从线下Excel批量导入考核成绩（过渡期用）；导出的数据含公式可直接用于二次加工。支持历史数据追溯。

### 44. [45] 管理部门（HR/管理员）端 / 数据与报表 / 绩效等级评定

**功能**：根据预设等级规则（如优秀、良好、称职、基本称职、不称职），按综合得分分布自动评定绩效等级。管理员可调整等级阈值和分布比例。

### 45. [46] 管理部门（HR/管理员）端 / 数据与报表 / 考核统计分析看板

**功能**：绩效数据可视化看板：各部门平均分对比、得分趋势（月度/季度）、等级分布、加减分统计、评分人评分等。
**人才开发部反馈**：员工可查询/导出个人历史分数统计数据

### 46. [47] 管理部门（HR/管理员）端 / 数据与报表 / 人力资源数据关联

**功能**：考核结果关联人力资源数据（调薪/晋升/培训等），支持按考核等级筛选人员、输出晋升/调薪/培训建议名单。
**备注**：1.0版先不处理

### 47. [48] 管理部门（HR/管理员）端 / 数据与报表 / 全年综合得分

**功能**：年度考核完成后自动计算全年综合得分：年度考核得分×60%+季度考核平均分×40%。
**备注**：1.0版先不处理
年度考核中的一项得分

### 48. [49] 管理部门（HR/管理员）端 / 评价关系配置 / 领导能力评价配置

**功能**：管理员配置年度领导能力评价问卷，设定评价维度、评价人类型（上级60%/同级20%/下级20%）、评分规则等。

### 49. [50] 管理部门（HR/管理员）端 / 评价关系配置 / 评分人权重配置

**功能**：按考核周期（月度、季度、年度 ）和岗位职级（员工主管级、经理总监级、副总级）配置不同评分人权重。
月度：自评20%+上级80%；季度：自评20%+上级40%+分管40%；年度总经理：自评40%+总裁办60%。

### 50. [51] 管理部门（HR/管理员）端 / 评价关系配置 / 多级评分关系配置

**功能**：支持配置多级审批和评分关系：直接上级评分→分管领导评分→HR审核→总经理确认。各节点可配置是否必须。
**人才开发部反馈**：月度评分关系：直接上级评分（经理级以上）→分管领导审核，保留总经理修改评分及确认功能但不是必须节点
季度绩效评价关系：直接上级评分→分管领导评分→总经理确认，HR属于外部审核，不需要在流程内，保留HR退回和建议功能

### 51. [52] 管理部门（HR/管理员）端 / 评价关系配置 / 评分关系临时调整

**功能**：支持因组织架构变动/人员异动等特殊情况临时调整评分关系，调整有记录可追溯。
**备注**：1.0版先不处理
