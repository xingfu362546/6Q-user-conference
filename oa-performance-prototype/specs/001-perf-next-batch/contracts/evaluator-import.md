# Contract: 评价人导入

**Page**: `prototype/oa-pc/hr-evaluators.html`

## 文件

UTF-8 CSV。第一行必须是：

```text
员工工号,评价人工号,员工姓名,评价人姓名
```

后两列可以留空。编码不是 UTF-8，或表头对不上，整份文件拒绝，不写入。

## 校验顺序

先读完每一行，再决定写不写。出现下面任何一条，整批写入行数是 0，并列出行号、工号和原因：

- 员工工号在人员名单中不存在
- 评价人工号在人员名单中不存在
- 评价人工号等于员工工号
- 同一员工工号在文件里出现超过一次
- 填了员工姓名或评价人姓名，但和该工号的主数据不一致

姓名留空时只看工号。

## 成功时

只更新文件里出现的员工。文件里没有的员工，原来的评价人不变。

更新之后，这些员工名下还没完成上级评分的待办，当前处理人改为新评价人。已经评完的那次评分，评分人姓名不改。

## 单条修改

页面上改某一个评价人工号，使用和导入同一套校验。不通过就不保存这一行。
