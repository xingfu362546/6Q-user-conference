# 交付说明 · v1.5.3

本次只做页面和规则调优，不新增 v1.6.0 的面谈流程。需求正文仍是 [spec.md](spec.md)，本文件说明改了什么、页面上看哪里。

## 一、改的规则

| 条款 | 改成什么 |
| --- | --- |
| FR-005 | 专项最多 5 条；横表一行一条；每条 1 个附件，支持图片和 PDF，单文件 2MB、合计 4MB，可预览 |
| FR-011 | 下季目标每条后面选是否跟上级对标，带挑战、资源和备注；不展示权重、不做权重校验；季度填表和评分页不再有面谈 |
| FR-012 | 待员工确认和已完成时 HR 都能改总分；改完状态不变 |
| FR-013 / FR-029 | 确认页四项：计算总分、上级核定、HR 最终总分、采用分；采用分 = HR 最终总分 ?? 计算总分 |
| FR-014 / FR-015 | 退至按状态限制；员工填写中没有退至；已完成不能退至 |
| FR-024 / FR-036 | 状态改为未开始、填写中、已逾期、待上级评价、待分管评价、待员工确认、已完成、已失效；待员工确认只等员工 |
| FR-026 | 导出图片改为导出 PDF，文件名「姓名-考核期.pdf」 |
| FR-032 | 保存不再提到分管核定分；只有 HR 最终总分独立存放 |
| FR-037 | 输入 0 分红字提醒，提交时二次确认，草稿不拦 |
| FR-038 | 专项附件三处共用：员工、上级评分、人才开发部核定 |

## 二、页面调整

| 页面 | 调整 |
| --- | --- |
| 员工 · 季度填表 | 专项从竖向卡片改为横表；最多 5 条；每条可传 1 个附件并预览；删掉「绩效面谈」步骤，季度从 9 步变 8 步 |
| 员工 · 季度填表 · 下季目标 | 每条目标一行：关键目标、考核目标、考核标准、是否对标、挑战资源、备注；底部不再单独一块；权重列和权重校验去掉 |
| 员工 · 月/季填表 | 自评填 0 时，分数下方红字「是否确认为 0 分？」；提交时再确认一次 |
| 领导 · 季度评分 | 专项区块增加附件列，可预览；删掉面谈只读区；删掉分管改总分入口 |
| 领导 · 待我审核 | 删掉「改总分」按钮；改为提示最终总分由 HR 核定 |
| HR · 待办详情 · 专项核定 | 增加附件列，可预览；0 分同样红字提醒 |
| 确认页 | 从五项改为四项，去掉「分管核定」；待员工确认只等员工点确认 |
| 计划明细 | 状态与筛选项换成新状态集；退至按状态限制；已完成只保留改总分和导出 PDF |
| 计划管理 · 编辑 | 弹窗改为表单，可改名称、启动时间、员工填写截止、上级评分截止、确认截止 |
| 评价人维护 | 上级和分管改成从组织架构选人：弹窗左侧部门、右侧人员，支持搜索，本人不可选，选中自动带出工号；分管可清除。一行同时维护两个人，导入表头改为员工工号,上级工号,分管工号,员工姓名,上级姓名,分管姓名 |
| 计划明细 / 评分页 | 按钮「导出图片」改为「导出PDF」，打印对话框里选另存为 PDF |

## 三、没做的

- v1.6.0 的季度面谈流程：发起面谈、填写面谈表、带出下月目标确认、工作亮点、待提升、改进计划、所需支持。本期只把季度考核里的面谈节点删掉，面谈内容和入口都不做。
- 面谈表的数据结构、权限和审批链不在本版。

## 四、开发看哪里

- 规则：spec 的 FR-005、FR-011 到 FR-015、FR-024、FR-026、FR-029、FR-032、FR-036 到 FR-038。
- 页面注释：计划明细注释 5、确认页注释 1、评价人注释 1、季度评分注释 3/4，标签都是 v1.5.3。
- 附件、0 分、PDF 三个新组件：`perf-attachment.js`、`perf-zero-warn.js`、`perf-export-image.js` 的 `exportPdf`。
