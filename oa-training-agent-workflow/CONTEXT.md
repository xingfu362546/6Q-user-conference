# Context · OA 培训学习模块（工作流子项目）

本文件为 **`oa-training-agent-workflow`** 单上下文词汇表；详细页面与发版约定以上级原型交接为准。

## 产品范围

- **域**：企业 OA 中的 **培训学习**（课程、进度、计划、考试等）。
- **本工作区职责**：issue / PRD / triage 的落盘与 Agent 可读约定，不替代原型实现。
- **原型与交接（权威细节）**：`../oa-training-prototype/DEVELOPER_HANDOFF.md`；功能矩阵与入口：`../oa-training-prototype/index.html`。

## 术语（简表）

| 术语 | 含义 |
|------|------|
| 员工端 | 学员/员工使用的壳与培训子页（侧栏含「学员学习」「课程管理」等分组）。 |
| 课程管理 | 原管理端培训能力在原型中的目录分组；现网由权限控制是否展示。 |
| 迭代 / 新增 | 见交接文档：迭代为域内增强；新增为新模块或清单未单独成行的端到端能力。 |
