## 原型与正式环境差异（必读）

### 登录校验

| | 原型（当前） | 正式开发（必须） |
|--|-------------|------------------|
| 密码 | **不校验**；点「登录」即可进 | 校验会员密码（或统一认证） |
| 图形验证码 | UI 保留，**不校验** | 必填且服务端校验 |
| 账号为空 | 默认进入演示面谈官 `iv_demo` | 拒绝登录，提示填写 |
| 账号错误 | 同样默认 `iv_demo`（便于演示） | 提示账号或密码错误 |
| 会话 | `localStorage` mock | 服务端 session / token，过期与注销 |

**验收提示：** 演示时无需输入密码/验证码；讲需求时说明「正式需账号+密码+验证码校验，且对接会员体系」。

### 其它仍属 mock、需正式实现

- 会务列表：按「进行中 ∩ 面谈官角色」从会务服务拉取，不可写死 3 场  
- 无会务空态文案保持：「当前无正在进行中的会务」  
- 学员意向 / 画像：对接真实接口；字段口径与运营后台只读一致  
- 权限：非面谈官不可见业务数据；不可进运营后台  

---

## 演示路径（30 秒）

1. 打开登录页 → 直接点「登录」  
2. 选任意一场进行中会务 → 意向列表  
3. 点学员姓名 → 画像（含 AI）  
4. （可选）退出后填手机 `13900002222` 再登录 → 看无会务空态  

---

## 建议接口边界（正式）

1. `POST /auth/login`：手机或邮箱 + 密码 + captcha → token + 会员身份  
2. `GET /interviewer/conferences?status=ongoing`：当前用户面谈官会务  
3. 意向列表 / 画像：复用会务后台只读 API，按 `conferenceId` 鉴权
