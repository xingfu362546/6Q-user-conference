## 1. 问题与目标

会务「面谈官」是**会务内角色**，赋权给原业务系统的**会员用户**。面谈官往往不是可进运营后台的全职员工账号，需要独立 PC 门户：

1. 用会员账号登录  
2. 选择自己当前参与的、**进行中**的会务  
3. 查看该会务全部学员（呈现对齐「学员意向分析」）  
4. 进入学员画像档案做面谈准备（含 AI 问答）

**成功标准（原型）：** 未登录→登录→选会务→列表→明细抽屉 / 画像（含行为·跟进·AI）全链路可点通；无策略配置、无跟进入录、无导出。

---

## 2. 角色、账号与权限

| 维度 | 规则 |
|------|------|
| 账号来源 | 原业务系统**会员**数据（手机号 / 邮箱 + 密码） |
| 业务角色 | 会务内角色 **6Q面谈官**（运营在原系统赋予） |
| 系统边界 | **不能**进入运营后台；**只能**进入本门户 |
| 学员数据范围 | 所选会务内的**全部学员**（非「仅分配给我」） |
| 功能权限（一期） | **只读查档**：不可改策略、不可录跟进、不可导出 |
| 字段口径 | 与运营后台意向列表 / 查看明细 / 画像**完全一致**（只读） |
| 无可用会务 | 允许登录；会务选择页空态：「当前无正在进行中的会务」 |

---

## 3. 信息架构

```text
登录（手机 | 邮箱 + 密码 + 图形验证码）
  └─ 会务选择（进行中 ∩ 本人面谈官）
        └─ 门户壳（橙系）
              ├─ 学员意向分析列表（默认落地 = 本门户学员列表）
              │     └─ 查看明细（只读：标签命中 + 洞察与推荐）
              └─ 画像档案（点学员姓名进入）
                    ├─ 行为四 Tab + 查看更多
                    ├─ 跟进查看更多
                    └─ AI 问答（保留，非正式商机模块）
```

### 3.1 明确不做（v1.0.3）

- 策略模板 / 本期策略配置及一切策略写入模块  
- 跟进入录、导出  
- 单独「学员信息」列表页（与意向列表合并为同一入口）  
- 未开始 / 已结束会务的进入  
- 运营后台蓝壳菜单（会务管理、工具箱等）

## 4. 页面与交互

### 4.1 登录

- UI 对齐已确认登录稿：标题「欢迎登录」；Tab「手机登录 / 邮箱登录」；密码显隐；图形验证码；主按钮「登录」（橙主色）  
- 原型：验证码可 mock（固定码或任意非空通过）；账号可用预设会员 mock  
- 成功 → 会务选择页  

### 4.2 会务选择

- 仅展示**进行中**且当前用户具备面谈官角色的会务  
- 原型 mock **2～3 场**；场内学员数据可复用**同一套**  
- 点选一场 → 写入「当前会务」上下文 → 进入意向列表  
- 空态文案：**当前无正在进行中的会务**（不可进入列表/画像）

### 4.3 学员意向分析列表（默认首页）

- 列与只读数据对齐运营后台意向分析（意向分/度、命中标签、跟进内容（当前会务）、AI、推荐等）  
- **不**展示策略配置入口、导出、运营 KPI/策略条（若后台有且属运营配置向，门户不搬）  
- 点**学员姓名** → 画像档案（页顶落地；不锚点、不自动弹行为抽屉）  
- **查看明细** → 只读抽屉：标签命中 + 洞察与推荐（无历史跟进 Tab、无行为四 Tab）  
- 顶栏展示当前会务；提供**切换会务**（回会务选择页）

### 4.4 画像档案

- 三栏事实档案、家庭组、关系图谱、基础信息、行为四 Tab + 更多、跟进更多、AI 问答：与后台 v1.0.2 只读口径一致  
- 返回 → 当前会务意向列表（保留会务上下文）

### 4.5 路由与会话守卫

| 条件 | 行为 |
|------|------|
| 未登录访问业务页 | → 登录 |
| 已登录、无当前会务，访问列表/画像 | → 会务选择 |
| 退出登录 | 清登录态与会务上下文 → 登录 |

## 5. 视觉

- **登录 + 门户壳**：独立橙系（对齐登录稿），产品名体现「6Q面谈官」  
- **内容区**：复用意向列表 / 画像的信息结构与组件逻辑，换门户 CSS 变量，避免整页呈现运营后台 Ant 蓝壳  
- 与 `6q-conference-prototype` 视觉一眼可区分

## 7. 验收清单（原型）

1. 手机号+密码、邮箱+密码均可登录（含验证码交互）  
2. 有会务：可见 2～3 场进行中会务并可进入  
3. 无会务账号/状态：空态「当前无正在进行中的会务」  
4. 列表呈现对齐意向分析；无策略配置/导出  
5. 查看明细仅两块只读内容；点姓名进画像页顶  
6. 画像含行为/跟进更多与 AI 问答；字段与后台一致  
7. 顶栏可切换会务；守卫规则生效  
8. 清单与 changelog 已标 **v1.0.3**

---

## 8. 决策摘要（已拍板）

1. 独立新门户（非后台角色裁剪）  
2. 账号=会员；权限来自会务内面谈官角色  
3. 看会务全部学员；一期只读  
4. 登录=手机/邮箱+密码+图形验证码  
5. 仅进行中会务可选；路径=登录→选会务→列表  
6. 页面=意向列表(=学员列表)+明细抽屉+画像（含 AI）；不搬策略模块  
7. 无会务可登录+空态提示  
8. 字段与后台完全一致  
9. 视觉=橙系独立壳  
10. 实现=独立目录+复用数据逻辑；版本 **v1.0.3**
